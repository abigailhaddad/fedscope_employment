# [DEPRECATED] FedScope Employment Data

**This repository has been deprecated and is no longer maintained.**

All data has been removed from this repository. Please use the following resources instead:

## Where to find the data

- **New Repository**: [FedScope_new](https://github.com/abigailhaddad/FedScope_new) - The successor to this repository with updated data and improved processing.
- **Official OPM Data**: [data.opm.gov](https://data.opm.gov) - The official U.S. Office of Personnel Management open data portal.

## What happened to this repo?

This repository previously contained 140+ million federal employee records from 1998-2025 and 9.8+ million separations and accessions records. The data and processing code have been moved to [FedScope_new](https://github.com/abigailhaddad/FedScope_new).

For official federal employment statistics, visit [data.opm.gov](https://data.opm.gov).
